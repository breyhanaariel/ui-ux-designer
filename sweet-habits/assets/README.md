# 🖼️ Sweet Habits — Visual Asset Checklist

Place finished exports in this folder using these filenames so the markdown case study can reference them consistently.

## Required Portfolio Exports

| File | Content |
|---|---|
| `01-research-summary.png` | Competitive observations / research synthesis |
| `02-user-needs.png` | User needs / jobs or evidence-based persona |
| `03-primary-user-flow.png` | Primary habit flow |
| `04-wireframe-exploration.png` | Low-fidelity alternatives |
| `05-before-example.png` | Earlier iteration / baseline |
| `06-after-example.png` | Improved iteration |
| `07-ui-foundations.png` | Color, type, spacing, components |
| `08-final-ui-overview.png` | High-fidelity screen family |
| `09-usability-findings.png` | Real test findings after testing |
| `10-accessibility-review.png` | Contrast / target / motion / labels review |
| `11-handoff-example.png` | Figma Dev Mode / annotation example |
| `12-prototype-flow.png` | Connected interactive prototype map |
| `13-motion-states.png` | Interaction/motion states and reduced-motion alternative |

## Suggested Export Rules

- Export case-study visuals at a readable desktop width.
- Avoid tiny text inside screenshots.
- Use consistent margins and presentation frames.
- Keep annotations concise.
- When showing iterations, label **what changed and why**.
- Do not add research numbers unless they come from real testing.
