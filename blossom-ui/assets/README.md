# 🖼️ Blossom UI — Visual Asset Checklist

Place finished Figma exports in this folder using these filenames.

## Required Portfolio Exports

| File | Content |
|---|---|
| `hero.png` | Blossom UI cover / banner |
| `01-foundations.png` | Color, type, spacing, radius, elevation |
| `02-token-architecture.png` | Primitive → semantic → component token diagram |
| `03-buttons.png` | Button variants, sizes, states |
| `04-form-controls.png` | Inputs, selects, checkbox, radio, switch |
| `05-navigation.png` | Tabs + responsive navigation |
| `06-feedback-overlays.png` | Alerts, toast, dialog, tooltip |
| `07-accessibility.png` | Focus, contrast, error, reduced-motion examples |
| `08-responsive-examples.png` | Desktop/tablet/mobile application |
| `09-handoff-spec.png` | Component spec / Dev Mode / Storybook mapping |
| `10-example-product.png` | Full example screen built entirely with Blossom |

## Recommended Presentation

Every component showcase should include:
- Anatomy
- Variants
- States
- Spacing
- Accessibility
- Do / Don't
- Responsive behavior where relevant
