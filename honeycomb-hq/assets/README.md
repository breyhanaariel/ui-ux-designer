## 🌼 Hero Direction

The cover should immediately read as a professional B2B product:
- Warm honey accent
- Slate / charcoal UI
- Desktop dashboard as primary device
- Optional mobile companion screen
- Subtle honeycomb geometry
- Avoid making the product look like a children's app

## 📊 Case Study Presentation

For complex UI:
- Crop screens closely enough to read
- Zoom into one important interaction when needed
- Annotate the decision, not every visible element
- Show before/after reasoning
- Show responsive transformation
- Include system states, not just ideal screens

## 🧪 Research Rule

Do not create synthetic “research findings” as if they came from participants.

Until testing happens, label artifacts:
- Hypothesis
- Research plan
- Provisional role
- Design assumption
